# 应用自进化

应用自进化基于评测证据，对配置、Prompt、Skill 和 Plugin 实现进行可验证的迭代。
优化目标、数据和写入权限、交付格式由任务规定。

## 输入与职责

| 输入 | 用途 |
| --- | --- |
| 优化目标 | 定义目标行为、指标、资源预算及应保持的行为 |
| Application 或候选工作区 | 提供待分析、修改和验证的应用资产 |
| 配置与装配信息 | 确认资产路径、模型、注册能力、启用项及宿主依赖 |
| 评测证据 | 提供可用的输入、输出、反馈、指标和执行轨迹 |
| 变更历史 | 关联候选差异与已观察到的效果 |
| 写入与数据权限 | 确定文件修改范围和评测数据的可见范围 |

工作区路径相对于文件工具声明的根；资产路径以应用配置为准。

## 优化流程

1. **建立基线**：确认目标、证据范围和当前行为，区分失败、退化及需要保留的成功场景。
2. **确认生效关系**：检查资产是否存在、能力是否注册、是否启用以及是否允许修改。
3. **定位根因**：结合代表性成功与失败案例，判断问题来自指令、配置、工具接口、
   执行逻辑、动态上下文或资源预算。
4. **形成变更**：定义预期行为和适用范围，并同步调整相互依赖的配置、资产及实现。
5. **静态与装配验证**：检查字段、路径、schema、注册、筛选及引用一致性。
6. **行为验证**：使用任务授权的验证入口评估目标行为及回归影响，记录未验证项。
7. **交付评审结果**：提供实际变更、证据、验证结果及剩余问题，遵循任务规定的格式。

轨迹缺失不作为未执行某行为的直接证据；指标相关性不直接等同于因果。
是否必须提交修改、何时允许保持不变、是否自动发布候选，由任务或宿主策略决定。

## 优化对象

| 观察到的模式 | 配置或扩展方向 | 主要验证点 |
| --- | --- | --- |
| 工具选择或前置步骤错误 | Prompt、Tool description/rules、Skill 触发与流程 | 工具可见性、必要前置条件、成功场景回归 |
| 调用参数错误 | 参数 schema、枚举、默认值、说明和 handler | schema 与执行语义一致，非法输入处理 |
| 重复调用或无法完成 | 任务终止条件、工具结果、Middleware、模型策略 | 必要多步调用仍可完成，成本与完成质量 |
| 长对话丢失信息 | compaction、工具输出结构、模型预算 | 关键事实、工具批次及资产引用保留 |
| 缺少动态信息 | ContextProvider 或查询 Tool | 来源可靠性、注入失败、会话隔离与回写 |
| 专项流程不稳定 | 新建或改进 Skill、关联参考资源 | 激活与读取条件、例外处理、跨案例泛化 |
| 业务执行结果错误 | Tool handler 及应用业务模块 | 业务合约、授权、失败处理和幂等 |
| 公开输出不适配业务 | 已注册投影器选择或宿主 PublicProjector 扩展 | 输出合约、脱敏、投影失败和交付语义 |

变更可包含新配置组合或新注册能力；代码扩展遵循任务授权，Runtime 协议变更单独评审。

## 权限与候选管理

可配置不等于可写。Read-only Paths 以任务为准；配置受保护时，
只修改获授权且能生效的实现，将所需配置变更列为后续依赖。

新增 Skill 须发布资产并配置 enabled_skills、skill_roots；无配置写权限时，
改进已激活的可写 Skill，或将激活交由获授权的维护者。

候选管理器提供 staging Workspace 时，修改在工作区完成，由管理器校验净变化并发布快照。
正式候选、评测事实和保护策略按宿主合约管理。文件工具可能进一步限制符号链接、
隐藏文件和路径操作；这些限制由实际工具接口定义。
移动或删除祖先目录不得间接改变受保护内容，也不得通过复制受保护事实绕过边界。

## 评测隔离

改进过程使用任务授权的开发证据。Train、Validation、Test 的用途和可见范围由评测协议规定；
隔离的验证集、测试集及评分实现不作为候选调优输入。
应用改动应针对可泛化行为，不写入样例答案、评测标识符或隐藏事实。

加载成功不证明效果提升；以实际评测为准，外部验证不可用时列明待验证项。

## 评审记录

评审通常包含以下内容；标题、顺序及机器可读值以任务合约为准。

| 内容 | 要求 |
| --- | --- |
| 变更状态 | 与工作区最终净变化一致 |
| 问题诊断 | 根因假设、受影响的场景及适用范围 |
| 证据 | 支持和反驳判断的输入、输出、轨迹或指标 |
| 实际变更 | 文件、配置或接口的变化与预期效果 |
| 保留行为 | 必须保持的成功路径与约束 |
| 验证结果 | 已执行的检查、评测及未验证项 |
| 风险和剩余问题 | 回归风险、授权范围内未解决的问题及后续依赖 |
